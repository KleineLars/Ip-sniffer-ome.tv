# IP Sniffer Lite

A lightweight, real-time WebRTC IP Sniffer overlay for the browser (Lite version). It intercepts IP addresses directly via WebRTC srflx ICE candidates, displays the live IP address in a clean UI overlay, and periodically shows a left-side notification prompt to upgrade to the full version.

## Features

* **Direct WebRTC IP Capture:** Instantly sniffs connection IPs without requiring an external geolocation API key.
* **Minimal UI Overlay:** Displays a sleek status dot and live IP container in the top-right corner.
* **Auto-Copy IP:** Click the displayed IP address to instantly copy it to your clipboard.
